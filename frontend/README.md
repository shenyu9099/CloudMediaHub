# CloudMediaHub 前端 - 多页面应用

## 🎨 全新设计

CloudMediaHub 现在是一个**完整的多页面应用**，采用灰白黑现代简约风格！

---

## 📁 页面结构

### 1. **首页 (index.html)** - 欢迎页
- 🎯 **Hero 区域**: 大标题 + 行动号召按钮
- ✨ **特性介绍**: 6 大核心功能
- 📊 **统计数据**: 用户数、内容数、点赞数
- 📢 **CTA 区域**: 注册引导
- 📄 **页脚**: 产品链接、支持信息

### 2. **发现页 (discover.html)** - 浏览内容
- 🔍 **搜索框**: 搜索内容或标签
- 📁 **侧边栏**: 内容分类 + 热门标签
- 🎨 **内容网格**: 卡片式展示
- 🔄 **排序选项**: 最新 / 最热

### 3. **个人中心 (profile.html)** - 我的页面
- 👤 **个人信息**: 头像 + 用户名 + 邮箱
- 📊 **统计数据**: 内容数 / 点赞数 / 浏览数
- 📑 **标签页**:
  - 📁 我的内容
  - ❤️ 我的点赞

### 4. **上传页 (upload.html)** - 上传内容
- 📤 **拖拽上传**: 支持拖拽或点击选择
- 🖼️ **文件预览**: 实时预览上传的文件
- 📝 **表单字段**: 标题 / 描述 / 标签
- 📊 **进度条**: 实时显示上传进度

## 🚀 使用指南

### 1. 首次访问
1. 打开 `index.html`
2. 浏览首页介绍
3. 点击"开始探索"或"立即上传"

### 2. 浏览内容
1. 访问 `discover.html`
2. 使用侧边栏筛选
3. 点击卡片查看详情

### 3. 上传内容
1. 访问 `upload.html`
2. 拖拽或选择文件
3. 填写信息并上传

### 4. 个人中心
1. 登录后点击用户头像
2. 选择"个人中心"
3. 查看我的内容和点赞

## 🔧 技术栈

- **HTML5**: 语义化标签

- **Azure Logic Apps**: 后端 API

## 🎯 页面流程

```
首页 (index.html)
  ↓
  ├─→ 发现 (discover.html) → 详情 → 点赞/评论
  ├─→ 上传 (upload.html) → 上传成功 → 我的内容
```
